AMM-laboratoriet

Ét binært marked, tre prismekanismer. Samme spillere og samme tilfældige ordreimpulser sendes gennem dem alle, så forskellen du ser skyldes mekanismen.

Parametre
Scenarier
Marked

Skjult for spillerne. Informerede spillere ser den med støj.

0 = intet chok. Ved chokket skifter den sande sandsynlighed, fx efter et mål.

Operatør og cold start

Samme maks. tab i alle tre modeller, så de kan sammenlignes.

Spillere
Simulation

Prisudvikling

Sandsynlighed for JA efter hver handel. Stiplet linje er den sande sandsynlighed.

Operatørens resultat

Huset (LMSR, pulje) eller LP (CPMM), som om markedet blev afgjort nu.

Forventet = vægtet med den sande sandsynlighed. Maks. tab er startkapitalen.

Nøgletal

Alle kr-beløb er forventede værdier ved den aktuelle sande sandsynlighed, medmindre andet står.

Din handel

Sendes til alle tre markeder på én gang, så du kan se, hvordan samme ordre prissættes. Du har 10.000 kr i hvert marked.

Prispåvirkning

Pris efter ét køb af JA for x kr, fra markedets nuværende tilstand.

Handelslog

Seneste 60 handler, nyeste øverst.

Mekanismerne

CPMM · spiller mod spiller
Modpart
Puljen. Hver aktie er dækket af 1 kr indskud, så vinderne betales af tabernes penge plus LP'ens indskud.
Pris
p(JA) = NEJ / (JA + NEJ) JA · NEJ = k
Køb for a kr
a præges til a JA + a NEJ. NEJ bliver i puljen, puljen udleverer JA til k er bevaret.
Cold start
LP indskyder L kr = L JA + L NEJ. LP bærer ubalancen og kan tabe op mod L, når prisen går mod 0 eller 1.
LMSR · mod huset
Modpart
Huset på hver handel. Prisen bestemmes stadig af spillernes nettovolumen.
Pris
C(q) = b·ln(e^(qJA/b) + e^(qNEJ/b)) p(JA) = e^(qJA/b) / (e^(qJA/b) + e^(qNEJ/b)) køb Δ aktier koster C(q+Δ) − C(q)
Cold start
Maks. tab = b·ln(1/min(p0, 1−p0)), uanset volumen. Forventet subsidie ved fuld prisopdagelse = b·KL(p‖p0). b styrer dybden.
Pulje · parimutuel
Modpart
De andre spillere. Huset har kun sit startindskud i puljen.
Pris
p(JA) = JA-pulje / total udbetaling pr. kr = total / vinderpulje
Cold start
Startindskuddet giver åbningsodds og kan højst tabes. Udbetalingen kendes først ved lukning, og der kan ikke sælges undervejs.
  • Spillerne er heuristiske: informerede handler mod deres skøn, støjhandlere tilfældigt, momentum forlænger de seneste 8 handlers bevægelse.
  • Gebyr trækkes af indsatsen ved køb og af provenuet ved salg. I puljen trækkes det ved indsats i stedet for ved lukning.
  • Ikke med: ordrebog, LP'er der tilføjer eller trækker likviditet undervejs, liquidity-sensitive LMSR, kreditrisiko og latens.
