## Opgave
Implement all sound with raw WebAudio (CONTRACTS.md §5, PLAN.md §7). No files, no Tone.js. Buses sfx/music/ui → master limiter (DynamicsCompressor) at −1 dBFS; code-generated stereo IR reverb (two convolvers with crossfade for base 2.8 s vs storm 1.6 s); one-shots pre-rendered via OfflineAudioContext at unlock (async, in small chunks), played with playbackRate jitter from crand. SFX: FM bells (ratio 3.5, inharmonic, lovely) per column in D-dorian pentatonic for 'land' (col 0..7), chime ladder D5 F5 A5 C6 D6 F6… for 'chime' (step), resonant glass pings + filtered noise for 'shatter' (WIN only), a dry quiet tick for 'returnTick' (−18 dB, no chord), 'nettoCross' tick, 'markUp' glassy blip rising a semitone per level, 'mote' zip, 'levelUp' riser + inharmonic gong, 'sun' rising gong steps (level 1..3), 'anticipation' drone, rate-limited 'countTick', 'win' brass-like saw stack stingers per level 1..5 + formant 'aah', 'bigWin'. Storm: 'stormSwell' 40 Hz swell, 'stormRiser' reverse cymbal + roar riser (bandpass 200→6000 Hz + waveshaper), 'impact', 'glassXL', 'drop808' 55→30 Hz, 'letterSlam' ring-mod metal slam, 'waveBoom', 'reform' hum, 'summary', 'fade'. No coin sounds. MUSIC pre-rendered as loopable stems via OfflineAudioContext (idle, chunked): base 84 BPM D-dorian Dm9–Bbmaj7–Fmaj7–C6 (4 bars) with 5 layers (L0 pad + wind, L1 glass arp, L2 heartbeat pulse bass, L3 soft percussion, L4 tension ostinato + crackle), gains switch on bar boundaries via setBaseLayers(n); storm 140 BPM D-phrygian (kick 150→45 Hz, reese bass, synthetic breaks, sidechain pumping) with stormLevel(x) adding supersaw stabs at x≥8, double-time hats at x≥32, formant choir at x≥128. Scheduler: look-ahead timer 25 ms / 120 ms horizon. startStorm(atCtxTime) must start exactly on that time (the cinematic downbeat). unlock(): resume ctx + silent buffer (iOS), handle 'interrupted' state; suspend/resume for visibilitychange. now() = ctx.currentTime (fallback performance.now()/1000 when locked). High-pass sub at 35 Hz. Must never clip; mix sparse and classy (premium Nordic, glassy, cinematic), not arcade. Harness dev/audio.html with buttons for every sfx + layer controls, and an automated headless check (dev/audio-check.mjs with playwright-core) that renders each SFX and 8 bars of each music stem via OfflineAudioContext and asserts: non-silent (RMS > threshold), peak ≤ 0.99, no NaN, loop seam continuity (first/last samples close), durations sane; print a table. Keep main-thread cost low (no per-beat node storms: stems + sparse live nodes).
